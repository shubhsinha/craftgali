# Craftgali — Product Requirements Document

## Overview
A marketplace for artisans and craftspeople to list, auction, and sell handcrafted goods. Connects artists directly with collectors.

| F-10 | User Reputation        | planned |
| F-11 | Bid Validation         | planned |

## User Roles
- **Artist** — lists artworks, manages auctions, receives payments
- **Collector** — browses, bids, purchases, messages artists
- **Admin** — moderation, commission management
